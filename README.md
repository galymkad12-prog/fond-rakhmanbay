# Сайт фонда «Рахманбай»

Одностраничный сайт благотворительного фонда в Аральске. Фонд поддерживает школьников, которые учатся на «3». Весь сайт помещается в один файл `index.html` и не требует сервера.

- Языки: русский и казахский, переключатель «ҚАЗ / РУС» в шапке. Выбор языка запоминается в браузере. Ссылка с `#kk` в конце сразу открывает казахскую версию.
- Разделы: о фонде, программы, этапы работы, кто может участвовать, форма заявки, как помочь (Kaspi, реквизиты, наставничество, бизнес), прозрачность, вопросы, контакты.
- Тёмная тема включается автоматически по настройке телефона.

## 1. Заполните данные фонда

Откройте `index.html` в любом текстовом редакторе (Блокнот, VS Code) и найдите блок `var CONFIG = {` в начале скрипта, внизу файла. Впишите значения между кавычками:

| Поле | Что вписать |
|---|---|
| `orgFullName` | полное юридическое наименование |
| `bin` | БИН фонда |
| `story.ru` / `story.kk` | 1–2 предложения: кто основал фонд и в честь кого он назван |
| `address.ru` / `address.kk` | адрес в Аральске |
| `hours.ru` / `hours.kk` | часы работы |
| `phone` | телефон, например `+7 701 123 45 67` |
| `whatsapp` | номер WhatsApp фонда. **Без него заявки не уходят в WhatsApp**, родителю предлагается только скопировать текст |
| `email`, `instagram`, `telegram` | почта, аккаунты без `@` |
| `kaspiPhone` | номер для переводов через Kaspi |
| `bank.*` | получатель, БИН, ИИК (IBAN), банк, БИК, Кбе, КНП. Для НКО Кбе обычно 18, КНП для благотворительной помощи обычно 119: уточните в своём банке |
| `reportsUrl` | ссылка на папку с отчётами (например, Google Диск) |
| `mapUrl` | ссылка на адрес в 2ГИС или Google Maps |

Пока поле пустое, строка на сайте просто скрыта. Если пусты все реквизиты или все контакты, вместо них показана фраза «появятся здесь в ближайшее время». Уже заполнено: история фонда (имени Рахмана Кадирханова) и часы работы (20:00–03:00).

## 2. Проверьте тексты

Программы (репетиторы, наставник, кружки, стипендия за рост, школьные наборы, профориентация), правила участия и ответы на вопросы написаны как черновик. Отредактируйте их под реальную работу фонда:

- русский текст находится прямо в HTML;
- казахский текст находится в блоке `var KK = {` (тот же ключ, например `prog4_d`).

Меняйте текст в обоих местах, чтобы версии совпадали.

## 3. Как работает заявка

Сайт не хранит данные. Родитель заполняет форму, сайт собирает текст заявки, и родитель отправляет его в WhatsApp фонда одной кнопкой или копирует его. Так не нужен сервер и база данных.

## 4. Как опубликовать бесплатно

- **Netlify Drop**: откройте app.netlify.com/drop и перетащите туда папку `fond-rakhmanbay`. Через минуту появится ссылка вида `...netlify.app`.
- **GitHub Pages**: создайте репозиторий, загрузите `index.html` и включите Pages в настройках.
- Свой домен (например, `rakhmanbay.kz`) подключается в настройках любого из этих сервисов.
